# Super Shout 2.0

- Apple SpeechAnalyzer transcription on macOS 26 with automatic model preparation and a classic-engine fallback.
- Phone and meeting mode with separate local-microphone and computer-audio transcripts.
- AI meeting summaries, decisions, action items, open questions, and Markdown export.
- Live microphone diagnostics for no signal, quiet audio, good signal, and clipping.
- Automatic formatting modes by app, plus user-defined app groups.
- Voice snippets that expand spoken triggers into reusable text.
- Searchable transcript library with optional AI recall across recent history.
- Signed Sparkle updates that download and install automatically after this release.
